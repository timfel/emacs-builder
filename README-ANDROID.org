#+TITLE: Shared-UID Emacs and Termux APKs
#+AUTHOR: Tim Felgentreff
#+PROPERTY: header-args :eval never

* Purpose

This document describes the Android build published by this repository.  It
builds GNU Emacs from an official Emacs source tag, configures it with
~--with-shared-user-id=com.termux~, and pairs it with an official Termux APK.
Both final APKs are signed with the same certificate so Emacs can access
Termux's files and packages.

Android's shared-user feature is deprecated, but it is the mechanism supported
by the upstream Emacs Android port for sharing an application's data.  The
upstream Emacs documentation describes this exact Termux configuration in
~java/INSTALL~.  Installing these APKs replaces the signatures from upstream
projects.  An existing upstream Emacs or Termux installation must therefore
be uninstalled first, and updates must continue to use the same keystore.

This is a complete rewrite of the scripts originally imported from
[[https://github.com/mikeyobrien/emacsapk][mikeyobrien/emacsapk]].  The
unconnected import branch and its initial commit remain in this repository so
the provenance is visible in the Git history.

* Sources and output

- Emacs source: the official GNU Emacs repository, mirrored at
  [[https://github.com/emacs-mirror/emacs][emacs-mirror/emacs]].
- Emacs Android build instructions: the upstream source file
  [[https://git.savannah.gnu.org/cgit/emacs.git/tree/java/INSTALL][java/INSTALL]].
- Termux: [[https://github.com/termux/termux-app/releases][official Termux app releases]], using the ~github-debug~ arm64 APK.
- Android dependencies: the pinned dependency sources selected by upstream's
  ~admin/download-android-deps.sh~.  SourceForge is used there for source
  tarballs, not for an Emacs APK.
- Output: a source-built Emacs APK, an official Termux APK, SHA-256 sidecars,
  and a build-info file.

The workflow resolves the newest numbered Emacs release tag from the official
Emacs mirror and the newest non-draft Termux release from the GitHub API every
time it runs.  It runs weekly and can also be started manually.  The current
workflow builds ~arm64-v8a~, the architecture used by ordinary Android phones.

* Local use

The source build needs Java 17, GNU build tools, ~curl~, ~git~, ~unzip~, and
an Android SDK containing:

- the Android platform API level required by the selected Emacs source tag;
- build-tools 35.0.0; and
- NDK 27.2.12479018 or newer.

The GitHub runner installs these tools automatically.  To tangle and run the
same build locally:

#+begin_src sh :eval never
sudo apt-get install autoconf automake build-essential curl file git \
  gawk libdigest-sha-perl libtool m4 pkg-config texinfo unzip zip
# Install the Android platform API level required by the selected Emacs tag,
# build-tools 35.0.0, and NDK 27.2.12479018
# using sdkmanager, then:
mkdir -p .build-android
emacs --batch --quick \
  --eval '(require (quote org))' \
  --eval '(org-babel-tangle-file "README-ANDROID.org")'
.build-android/build-android.sh
ls .build-android/output/
#+end_src

The default local keystore is created at
~.build-android/android.keystore~.  A build can use another keystore with
~KEYSTORE_PATH~, ~KEYSTORE_PASSWORD~, ~KEY_PASSWORD~, and ~KEY_ALIAS~.

For a stable signing identity, configure these GitHub Actions secrets:

- ~ANDROID_KEYSTORE_BASE64~: base64-encoded JKS or PKCS#12 keystore;
- ~ANDROID_KEYSTORE_PASSWORD~;
- ~ANDROID_KEY_PASSWORD~; and
- ~ANDROID_KEY_ALIAS~.

If no keystore secret is configured, the workflow creates an ephemeral key.
That is sufficient for the pair produced by one run, but a later run will
require uninstalling the previous APKs before installation.

* Installation

Install both APKs from the same workflow run.  If either upstream application
is already installed, remove it first because its signing certificate differs:

#+begin_src sh :eval never
adb uninstall org.gnu.emacs || true
adb uninstall com.termux || true
adb install emacs-*-shared-signed.apk
adb install termux-*-shared-signed.apk
#+end_src

After Termux has bootstrapped its package environment, Emacs can invoke
programs such as ~git~, ~python~, and ~gcc~ from Termux.  The common Android
UID provides the filesystem permissions; it does not make Termux packages
available until Termux itself has initialized them.

* Build implementation

The complete implementation is kept in this document.  Tangling it creates
one ignored local build script and the workflow committed below.  Keeping the
script here makes the release procedure reviewable without maintaining a
separate library of shell files.

#+begin_src bash :tangle .build-android/build-android.sh :tangle-mode (identity #o755)
#!/usr/bin/env bash
set -euo pipefail
trap 'status=$?; printf "[android] build failed at line %d (status %d): %s\n" "$LINENO" "$status" "$BASH_COMMAND" >&2' ERR

SCRIPT_DIR=$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)
ROOT=$(cd -- "$SCRIPT_DIR/.." && pwd)
BUILD_DIR=${BUILD_DIR:-"$ROOT/.build-android/work"}
CACHE_DIR=${CACHE_DIR:-"$ROOT/.build-android/cache"}
OUTPUT_DIR=${OUTPUT_DIR:-"$ROOT/.build-android/output"}

EMACS_REPOSITORY=${EMACS_REPOSITORY:-https://github.com/emacs-mirror/emacs.git}
EMACS_REF=${EMACS_REF:-}
EMACS_VERSION=${EMACS_VERSION:-}
TERMUX_VERSION=${TERMUX_VERSION:-}
TERMUX_REPOSITORY=${TERMUX_REPOSITORY:-termux/termux-app}

ANDROID_ARCH=${ANDROID_ARCH:-arm64-v8a}
ANDROID_API_LEVEL=${ANDROID_API_LEVEL:-}
ANDROID_MIN_API_LEVEL=${ANDROID_MIN_API_LEVEL:-29}
ANDROID_NDK_VERSION=${ANDROID_NDK_VERSION:-27.2.12479018}
BUILD_TOOLS_VERSION=${BUILD_TOOLS_VERSION:-35.0.0}
JOBS=${JOBS:-$(nproc)}

KEYSTORE_PATH=${KEYSTORE_PATH:-"$ROOT/.build-android/android.keystore"}
KEYSTORE_PASSWORD=${KEYSTORE_PASSWORD:-android}
KEY_PASSWORD=${KEY_PASSWORD:-android}
KEY_ALIAS=${KEY_ALIAS:-androiddebugkey}

log() { printf '[android] %s\n' "$*" >&2; }
fatal() { printf '[android] ERROR: %s\n' "$*" >&2; exit 1; }

require_command() {
    command -v "$1" >/dev/null 2>&1 || fatal "Required command not found: $1"
}

emacs_version_from_ref() {
    local version=${1#emacs-}
    [[ $version =~ ^[0-9]+(\.[0-9]+){1,2}$ ]] || \
        fatal "Emacs ref is not a numbered release tag: $1"
    printf '%s\n' "$version"
}

latest_emacs_ref() {
    local ref
    ref=$(git ls-remote --tags --refs "$EMACS_REPOSITORY" |
        sed -nE 's#^[0-9a-f]+[[:space:]]+refs/tags/(emacs-[0-9]+\.[1-9][0-9]*(\.[0-9]+)?)$#\1#p' |
        sort -Vu | tail -n1 || true)
    [[ -n $ref ]] || fatal "Could not find a stable Emacs release tag"
    printf '%s\n' "$ref"
}

latest_emacs_api_level() {
    local api_level
    api_level=$(curl --fail --silent --show-error --location --retry 5 \
        --connect-timeout 30 \
        "https://raw.githubusercontent.com/emacs-mirror/emacs/$EMACS_REF/java/INSTALL" |
        sed -nE 's/.*API level ([0-9]+).*/\1/p' |
        head -n1 || true)
    [[ -n $api_level ]] || fatal "Could not determine the Android API for $EMACS_REF"
    printf '%s\n' "$api_level"
}

latest_termux_version() {
    local version
    version=$(curl --fail --silent --show-error --location --retry 5 \
        --connect-timeout 30 \
        "https://api.github.com/repos/$TERMUX_REPOSITORY/releases/latest" |
        sed -nE 's/.*"tag_name"[[:space:]]*:[[:space:]]*"v?([^"]+)".*/\1/p' |
        head -n1 || true)
    [[ -n $version ]] || fatal "Could not find the latest Termux release"
    printf '%s\n' "$version"
}

resolve_versions() {
    [[ -n $EMACS_REF ]] || EMACS_REF=$(latest_emacs_ref)
    EMACS_VERSION=${EMACS_VERSION:-$(emacs_version_from_ref "$EMACS_REF")}
    ANDROID_API_LEVEL=${ANDROID_API_LEVEL:-$(latest_emacs_api_level)}
    [[ -n $TERMUX_VERSION ]] || TERMUX_VERSION=$(latest_termux_version)
    printf 'emacs_ref=%s\n' "$EMACS_REF"
    printf 'emacs_version=%s\n' "$EMACS_VERSION"
    printf 'android_api_level=%s\n' "$ANDROID_API_LEVEL"
    printf 'termux_version=%s\n' "$TERMUX_VERSION"
}

select_android_arch() {
    case "$ANDROID_ARCH" in
        arm64-v8a)
            NDK_TRIPLE=aarch64-linux-android
            EMACS_ABI=aarch64
            DEPS_BITS=64
            ;;
        x86_64)
            NDK_TRIPLE=x86_64-linux-android
            EMACS_ABI=x86_64
            DEPS_BITS=64
            ;;
        armeabi-v7a)
            NDK_TRIPLE=armv7a-linux-androideabi
            EMACS_ABI=armv7
            DEPS_BITS=32
            ;;
        *)
            fatal "Unsupported Android architecture: $ANDROID_ARCH"
            ;;
    esac
}

find_android_sdk() {
    SDK_ROOT=${ANDROID_SDK_ROOT:-${ANDROID_HOME:-}}
    [[ -n $SDK_ROOT && -d $SDK_ROOT ]] || \
        fatal 'ANDROID_SDK_ROOT or ANDROID_HOME is not set'

    SDK_BUILD_TOOLS="$SDK_ROOT/build-tools/$BUILD_TOOLS_VERSION"
    ANDROID_JAR="$SDK_ROOT/platforms/android-$ANDROID_API_LEVEL/android.jar"
    NDK_ROOT="$SDK_ROOT/ndk/$ANDROID_NDK_VERSION"
    NDK_HOST_TAG=${NDK_HOST_TAG:-linux-x86_64}
    NDK_TOOLCHAIN="$NDK_ROOT/toolchains/llvm/prebuilt/$NDK_HOST_TAG"
    ANDROID_CC="$NDK_TOOLCHAIN/bin/${NDK_TRIPLE}${ANDROID_MIN_API_LEVEL}-clang"

    [[ -f $ANDROID_JAR ]] || fatal "Android API $ANDROID_API_LEVEL is not installed"
    [[ -x $SDK_BUILD_TOOLS/aapt ]] || fatal "aapt is missing from $SDK_BUILD_TOOLS"
    [[ -x $SDK_BUILD_TOOLS/apksigner ]] || fatal "apksigner is missing from $SDK_BUILD_TOOLS"
    [[ -x $SDK_BUILD_TOOLS/d8 ]] || fatal "d8 is missing from $SDK_BUILD_TOOLS"
    [[ -x $SDK_BUILD_TOOLS/zipalign ]] || fatal "zipalign is missing from $SDK_BUILD_TOOLS"
    [[ -x $NDK_TOOLCHAIN/bin/${NDK_TRIPLE}${ANDROID_MIN_API_LEVEL}-clang ]] || \
        fatal "NDK compiler is missing: $ANDROID_CC"

    APKSIGNER="$SDK_BUILD_TOOLS/apksigner"
    AAPT2="$SDK_BUILD_TOOLS/aapt2"
    ZIPALIGN="$SDK_BUILD_TOOLS/zipalign"
}

fetch_termux_apk() {
    local destination="$CACHE_DIR/termux-${TERMUX_VERSION}-${ANDROID_ARCH}.apk"
    local url="https://github.com/$TERMUX_REPOSITORY/releases/download/v${TERMUX_VERSION}/termux-app_v${TERMUX_VERSION}%2Bgithub-debug_${ANDROID_ARCH}.apk"
    local temporary="${destination}.partial"

    mkdir -p "$CACHE_DIR"
    if [[ -s $destination ]] && unzip -tqq "$destination" >/dev/null 2>&1; then
        log "Using cached $(basename -- "$destination")"
        printf '%s\n' "$destination"
        return
    fi

    rm -f "$temporary"
    log "Downloading official Termux $(basename -- "$destination")"
    curl --fail --show-error --location --retry 5 --retry-delay 2 \
        --connect-timeout 30 --output "$temporary" "$url"
    unzip -tqq "$temporary" >/dev/null || \
        fatal "Downloaded Termux file is not an APK: $url"
    mv -- "$temporary" "$destination"
    printf '%s\n' "$destination"
}

build_emacs_from_source() {
    local source_dir="$BUILD_DIR/emacs"
    local deps_dir="$BUILD_DIR/android-deps"
    local ndk_path
    local -a apks

    rm -rf "$source_dir" "$deps_dir"
    mkdir -p "$BUILD_DIR" "$deps_dir"

    log "Cloning official GNU Emacs source at $EMACS_REF"
    git clone --depth 1 --branch "$EMACS_REF" "$EMACS_REPOSITORY" "$source_dir"

    log 'Generating the Emacs build system'
    (cd "$source_dir" && ./autogen.sh)

    log 'Downloading the pinned Android dependencies selected by upstream Emacs'
    (cd "$deps_dir" && sh "$source_dir/admin/download-android-deps.sh" "$DEPS_BITS")
    ndk_path=$(<"$deps_dir/search-path.txt")
    [[ -n $ndk_path ]] || fatal 'The Emacs Android dependency search path is empty'

    log 'Configuring GNU Emacs for Android and the Termux shared UID'
    (
        cd "$source_dir"
        ANDROID_CC="$ANDROID_CC" \
        SDK_BUILD_TOOLS="$SDK_BUILD_TOOLS" \
        ./configure \
            --with-android="$ANDROID_JAR" \
            --with-shared-user-id=com.termux \
            --with-ndk-path="$ndk_path" \
            --without-android-debug
    )

    log "Building GNU Emacs for $ANDROID_ARCH"
    (cd "$source_dir" && make -j"$JOBS" all)

    shopt -s nullglob
    apks=("$source_dir"/java/emacs-*.apk)
    (( ${#apks[@]} == 1 )) || \
        fatal "Expected one source-built Emacs APK, found ${#apks[@]}"
    EMACS_BUILT_APK=${apks[0]}
}

manifest_shared_user_id() {
    local apk=$1 value
    value=$(
        "$AAPT2" dump xmltree --file AndroidManifest.xml "$apk" |
            sed -nE 's/.*android:sharedUserId\([^)]*\)="([^"]+)".*/\1/p' |
            head -n1
    )
    [[ -n $value ]] || fatal "No android:sharedUserId found in $(basename -- "$apk")"
    printf '%s\n' "$value"
}

prepare_keystore() {
    mkdir -p "$(dirname -- "$KEYSTORE_PATH")"
    if [[ -n ${KEYSTORE_BASE64:-} ]]; then
        log 'Restoring signing keystore from KEYSTORE_BASE64'
        printf '%s' "$KEYSTORE_BASE64" | base64 --decode >"$KEYSTORE_PATH"
        chmod 600 "$KEYSTORE_PATH"
    fi
    if [[ ! -s $KEYSTORE_PATH ]]; then
        log 'Generating signing keystore'
        keytool -genkeypair -v \
            -keystore "$KEYSTORE_PATH" \
            -storepass "$KEYSTORE_PASSWORD" \
            -keypass "$KEY_PASSWORD" \
            -alias "$KEY_ALIAS" \
            -keyalg RSA -keysize 2048 -validity 10000 \
            -dname 'CN=Emacs Termux shared UID, O=Android, C=US' \
            >/dev/null 2>&1
    fi
}

certificate_fingerprint() {
    "$APKSIGNER" verify --print-certs "$1" 2>&1 |
        sed -nE 's/.*SHA-256 certificate digest:[[:space:]]*//p' | head -n1
}

resign_apk() {
    local source=$1 destination=$2 aligned="${destination}.aligned"
    rm -f "$aligned" "$destination"
    "$ZIPALIGN" -p -f 4 "$source" "$aligned"
    mv -- "$aligned" "$destination"
    KEYSTORE_PASSWORD="$KEYSTORE_PASSWORD" KEY_PASSWORD="$KEY_PASSWORD" \
        "$APKSIGNER" sign \
        --ks "$KEYSTORE_PATH" \
        --ks-key-alias "$KEY_ALIAS" \
        --ks-pass env:KEYSTORE_PASSWORD \
        --key-pass env:KEY_PASSWORD \
        "$destination"
    "$APKSIGNER" verify --verbose "$destination" >/dev/null
    "$ZIPALIGN" -c -P 16 -v 4 "$destination" >/dev/null
}

build() {
    require_command curl
    require_command git
    require_command unzip
    require_command keytool
    select_android_arch
    resolve_versions >/dev/null
    find_android_sdk
    prepare_keystore

    rm -rf "$OUTPUT_DIR"
    mkdir -p "$OUTPUT_DIR"

    local emacs_source termux_source
    build_emacs_from_source
    emacs_source=$EMACS_BUILT_APK
    termux_source=$(fetch_termux_apk)

    local emacs_uid termux_uid
    emacs_uid=$(manifest_shared_user_id "$emacs_source")
    termux_uid=$(manifest_shared_user_id "$termux_source")
    log "Emacs sharedUserId: $emacs_uid"
    log "Termux sharedUserId: $termux_uid"
    [[ $emacs_uid == "$termux_uid" ]] || \
        fatal 'The APKs do not declare the same sharedUserId'

    local emacs_output="$OUTPUT_DIR/emacs-${EMACS_VERSION}-${ANDROID_ARCH}-shared-signed.apk"
    local termux_output="$OUTPUT_DIR/termux-${TERMUX_VERSION}-${ANDROID_ARCH}-shared-signed.apk"
    resign_apk "$emacs_source" "$emacs_output"
    resign_apk "$termux_source" "$termux_output"

    local emacs_fingerprint termux_fingerprint
    emacs_fingerprint=$(certificate_fingerprint "$emacs_output")
    termux_fingerprint=$(certificate_fingerprint "$termux_output")
    [[ -n $emacs_fingerprint && $emacs_fingerprint == "$termux_fingerprint" ]] || \
        fatal 'The signed APK certificate fingerprints do not match'

    sha256sum "$emacs_output" >"$emacs_output.sha256"
    sha256sum "$termux_output" >"$termux_output.sha256"
    cat >"$OUTPUT_DIR/BUILD-INFO.txt" <<EOF
Emacs source: $EMACS_REPOSITORY
Emacs ref: $EMACS_REF
Termux repository: $TERMUX_REPOSITORY
Termux version: $TERMUX_VERSION
Architecture: $ANDROID_ARCH
Android API headers: $ANDROID_API_LEVEL
Android minimum API: $ANDROID_MIN_API_LEVEL
sharedUserId: $emacs_uid
SHA-256 signing certificate: $emacs_fingerprint
EOF
    log "Built $(basename -- "$emacs_output")"
    log "Built $(basename -- "$termux_output")"
}

case ${1:-build} in
    resolve)
        require_command curl
        require_command git
        resolve_versions
        ;;
    build)
        build
        ;;
    *)
        fatal "Usage: $0 [resolve|build]"
        ;;
esac
#+end_src

* GitHub Actions workflow

The workflow tangles this document before each job.  The resolve job supplies
immutable source and release values to the build job.  The build job installs
the official Android toolchain, compiles Emacs, downloads the official Termux
APK, verifies the shared UID, and re-signs both outputs with one key.  The
publish job puts the APKs and checksums on a GitHub release.

#+begin_src yaml :tangle .github/workflows/android.yml
name: Android Emacs and Termux APKs

on:
  schedule:
    - cron: '23 04 * * 1'
  workflow_dispatch:
    inputs:
      emacs_ref:
        description: Official Emacs release tag, for example emacs-30.2 (empty means latest)
        required: false
        default: ''
        type: string
      termux_version:
        description: Termux version (empty means latest)
        required: false
        default: ''
        type: string

permissions:
  contents: write
  actions: write

concurrency:
  group: android-apks
  cancel-in-progress: false

jobs:
  resolve:
    runs-on: ubuntu-22.04
    timeout-minutes: 10
    outputs:
      emacs_ref: ${{ steps.versions.outputs.emacs_ref }}
      emacs_version: ${{ steps.versions.outputs.emacs_version }}
      android_api_level: ${{ steps.versions.outputs.android_api_level }}
      termux_version: ${{ steps.versions.outputs.termux_version }}
    steps:
      - uses: actions/checkout@v7

      - name: Install Org for tangling
        run: |
          sudo apt-get update
          sudo apt-get install --yes --no-install-recommends emacs-nox

      - name: Tangle the Android build files
        run: |
          mkdir -p .build-android
          emacs --batch --quick --eval '(require (quote org))' \
            --eval '(org-babel-tangle-file "README-ANDROID.org")'

      - name: Resolve official source releases
        id: versions
        env:
          EMACS_REF: ${{ inputs.emacs_ref }}
          TERMUX_VERSION: ${{ inputs.termux_version }}
        run: .build-android/build-android.sh resolve >> "$GITHUB_OUTPUT"

  build:
    needs: resolve
    strategy:
      fail-fast: false
      matrix:
        include:
          - runner: ubuntu-22.04
            android_arch: arm64-v8a
    runs-on: ${{ matrix.runner }}
    timeout-minutes: 360
    env:
      EMACS_REF: ${{ needs.resolve.outputs.emacs_ref }}
      EMACS_VERSION: ${{ needs.resolve.outputs.emacs_version }}
      ANDROID_API_LEVEL: ${{ needs.resolve.outputs.android_api_level }}
      TERMUX_VERSION: ${{ needs.resolve.outputs.termux_version }}
      ANDROID_ARCH: ${{ matrix.android_arch }}
      ANDROID_KEYSTORE_BASE64: ${{ secrets.ANDROID_KEYSTORE_BASE64 }}
      KEYSTORE_PASSWORD: ${{ secrets.ANDROID_KEYSTORE_PASSWORD }}
      KEY_PASSWORD: ${{ secrets.ANDROID_KEY_PASSWORD }}
      KEY_ALIAS: ${{ secrets.ANDROID_KEY_ALIAS }}

    steps:
      - uses: actions/checkout@v7

      - name: Install Org and Emacs build dependencies
        run: |
          sudo apt-get update
          sudo apt-get install --yes --no-install-recommends \
            autoconf automake build-essential ca-certificates curl emacs-nox \
            file gawk git libdigest-sha-perl libtool libtool-bin m4 pkg-config \
            python3 texinfo unzip zip

      - name: Tangle the Android build files
        run: |
          mkdir -p .build-android
          emacs --batch --quick --eval '(require (quote org))' \
            --eval '(org-babel-tangle-file "README-ANDROID.org")'

      - name: Set up Java
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'

      - name: Set up Android SDK
        uses: android-actions/setup-android@v3

      - name: Install Android platform, build-tools, and NDK
        run: |
          yes | sdkmanager --licenses >/dev/null || true
          sdkmanager \
            "platforms;android-${{ needs.resolve.outputs.android_api_level }}" \
            "build-tools;35.0.0" \
            "ndk;27.2.12479018"

      - name: Build GNU Emacs from source and verify shared UID
        run: .build-android/build-android.sh build

      - name: Upload APKs
        uses: actions/upload-artifact@v7
        with:
          name: android-apks-${{ matrix.android_arch }}
          path: .build-android/output/*
          if-no-files-found: error
          retention-days: 90

  publish:
    needs: [resolve, build]
    runs-on: ubuntu-22.04
    timeout-minutes: 15
    env:
      EMACS_REF: ${{ needs.resolve.outputs.emacs_ref }}
      EMACS_VERSION: ${{ needs.resolve.outputs.emacs_version }}
      ANDROID_API_LEVEL: ${{ needs.resolve.outputs.android_api_level }}
      TERMUX_VERSION: ${{ needs.resolve.outputs.termux_version }}

    steps:
      - uses: actions/checkout@v7

      - name: Download APK artifacts
        uses: actions/download-artifact@v8
        with:
          pattern: android-apks-*
          path: dist
          merge-multiple: true

      - name: Publish GitHub release
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          stamp=$(date --utc +%Y%m%d-%H%M%S)
          tag="android-apks-${stamp}-${GITHUB_RUN_ID}-${GITHUB_RUN_ATTEMPT}"
          title="Android Emacs and Termux APKs ${stamp}"
          gh release create "$tag" dist/*.apk dist/*.sha256 dist/BUILD-INFO.txt \
            --target "$GITHUB_SHA" --title "$title" --latest \
            --notes "GNU Emacs $EMACS_REF built from source and Termux $TERMUX_VERSION, signed with one certificate and verified to declare the same Android sharedUserId."

      - name: Prune old Android releases
        uses: actions/github-script@v9
        with:
          script: |
            const prefix = "android-apks-";
            const releases = (await github.paginate(
              github.rest.repos.listReleases,
              { owner: context.repo.owner, repo: context.repo.repo, per_page: 100 },
            ))
              .filter(release =>
                !release.draft && release.tag_name.startsWith(prefix))
              .sort((a, b) =>
                new Date(b.published_at || b.created_at) -
                new Date(a.published_at || a.created_at));

            const keep = new Set(releases.slice(0, 4).map(release => release.id));
            for (const release of releases) {
              if (keep.has(release.id)) continue;
              core.info(`Deleting release ${release.tag_name}`);
              await github.rest.repos.deleteRelease({
                owner: context.repo.owner,
                repo: context.repo.repo,
                release_id: release.id,
              });
              try {
                await github.rest.git.deleteRef({
                  owner: context.repo.owner,
                  repo: context.repo.repo,
                  ref: `tags/${release.tag_name}`,
                });
              } catch (error) {
                if (error.status !== 404) throw error;
              }
            }

      - name: Remove superseded workflow artifacts
        uses: actions/github-script@v9
        with:
          script: |
            const artifacts = await github.paginate(
              github.rest.actions.listArtifactsForRepo,
              { owner: context.repo.owner, repo: context.repo.repo, per_page: 100 },
            );
            for (const artifact of artifacts) {
              if (!artifact.name.startsWith("android-apks-")) continue;
              if (String(artifact.workflow_run?.id) === String(context.runId)) continue;
              core.info(`Deleting superseded artifact ${artifact.id}`);
              await github.rest.actions.deleteArtifact({
                owner: context.repo.owner,
                repo: context.repo.repo,
                artifact_id: artifact.id,
